
# Admin Panel

Учебная админ-панель на React + TypeScript + Tailwind CSS.

🔗 **Демо:** https://viktorcvp.github.io/admin-panel/

## Стек

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- React Router v7
- JSONPlaceholder API

## Возможности

- 📊 Дашборд с карточками статистики
- 👥 Таблица пользователей с загрузкой с API
- ➕ CRUD: создание, редактирование, удаление
- 🎨 Адаптивная вёрстка
- 🚀 Деплой на GitHub Pages

## Локальный запуск

```bash
npm install
npm run dev
